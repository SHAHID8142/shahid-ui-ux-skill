# Fixture C — dashboard/CMS-admin surface (Next.js, Operate mode)

Synthetic control panel: KPI widgets, content-queue table, settings form.
CMS = the site's admin/control panel (D20) — no content-driven public pages.
All rows, counts and labels are invented; no real customer data, no auth
bypass hazards (login is a static demo screen with no backend). Landmarks:
`#admin-sidebar`, `#admin-topbar`, `#kpi-row`, `#content-queue`,
`#settings-form`, `#admin-footer`.
