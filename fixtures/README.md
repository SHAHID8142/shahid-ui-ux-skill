# fixtures/ — four self-contained fixture apps

One fixture per surface mode (marketing, e-commerce, dashboard/CMS-admin,
portfolio). In-repo, never published; test targets, not products (ADR-001).
Fixture A (marketing) is created by T0102; B/C/D by T0102b.
`fixtures/bestpractice/` is a scope test target (T1023): one element that is deliberately
undersized and clipped at 400% zoom, so a scoped proposal has a measured fact to report. The dual-stack
mapping spike (T0700) and evaluation baselines (T0153) require all four.
