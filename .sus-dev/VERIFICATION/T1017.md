# T1017 — G7's 400% zoom equivalence, measured instead of asserted

**Task:** close the residue named in issue #13: G7 shipped with one half measured (320 CSS px
reflow) and one half reported `not-run` on every run ("this harness does not drive browser zoom").
**Approval:** D32 issue triage (issue #13, P1) within D28 build authorization.
**Branch / base:** `chore/continuation-reconciliation` at `59c89bd`.

## What was wrong

The previous position was not dishonest, but it collapsed two different things. 400% zoom on a
1280×1024 window is a **320×256 CSS px viewport rasterised at device scale factor 4**. The
repository already visited 320 CSS px — but at 568 px tall and at raster scale 1. So the code was
measuring a phone viewport and then declaring the desktop zoom viewport unmeasurable, and a check
in `scripts/check-gates.mjs` **asserted that it stay unmeasurable**. That assertion is the defect:
it made the gap structural instead of a missing visit.

Measured on this machine (Chromium, `en`): the marketing fixture passes the zoom equivalence —
`320×256` CSS px, dsf 4, `scrollWidth 320 = clientWidth 320`, no clipping container. The negative
control page (`900 px` block) records `overflow: true` with a failing gate verdict, so the record
follows the page rather than the label.

## What this still does not do

- **The user-agent zoom setting is not driven.** Chromium's own zoom control and text-only zoom
  remain `not-run`; the names in every report say so.
- **One theme, one motion setting** for the zoom record (light, no-preference). A dark-theme or
  reduced-motion zoom visit is not run, and nothing claims it is.
- The zoom cell is layout evidence at a CSS px viewport, not a screenshot column: `captureMatrix`
  still photographs 390/768/1440 only.
- G10's labelled-corpus precision/recall, real assistive-technology sessions and field performance
  data are untouched by this task and remain as documented elsewhere.

## Rollback

Revert the files above; `zoom400` is additive, so older recorded evidence stays readable and
`evaluateZoom400` would simply report `not-run`.
