# T1018 — the research loader that was missing, and what its measurement does not claim

**Task:** close the last named gap in issue #14: the research provider could only serve a hit if a
loader supplied bytes matching the pin, and no shipped loader existed — so the provider arm of every
paired run was `not-run`. A missing part reported honestly is still a missing part.
**Approval:** D32 issue triage (issue #14, P2) within D28 build authorization.
**Branch / base:** `chore/continuation-reconciliation` at `0473abd`.

## What ships

| Path | Role |
| --- | --- |
| `packages/scanners/src/research-cache-loader.ts` | The loader. Reads `<guideId>.md` from a cache directory, hashes on read, serves **only** digest matches. Ranks candidates by identity tokens then cached-content tokens, shortlists within a factor of two of the best match, and returns the best-matching section padded to ≥300 characters (a heading with one line is a label, not an excerpt). Bounded: 512 KiB per file, the provider's own 1200-char excerpt cap, `limit` honouring, deterministic ordering. No network import exists in the file. |
| `packages/scanners/tests/research-cache-loader.test.ts` | 14 tests, mostly negative: digest mismatch refused with a named reason, undigested guide refused, unsafe ids (`../`, absolute, `a/b`, `Upper`, NUL) return `null`, oversize file refused before reading, read failure becomes a skip not an exception, offline flag defeats a perfect cache, excerpt picks the matching section without leaking the intro, excerpt cap exact, ordering deterministic, and the loader returns no title/licence/URL of its own so it cannot relabel content. |
| `scripts/research/cache-guides.mjs` | Opt-in cache filler (`SUS_RESEARCH_ONLINE=1`). Reuses `verify-pin.mjs`'s two-transport fetch, checks each digest against the pin **before** writing, writes `.sus-cache/research/modern-web-guidance/<guideId>.md` plus a digest-only manifest, and prints digests and byte counts — never guide text. |
| `scripts/research/paired-run.mjs` | Offline paired-run recorder. Runs a fixed four-topic set, records served guides, character counts, estimated tokens, digest/provenance presence and cap compliance, and writes **baseline** and **effectiveness** arms as `not-run` with reasons. |
| `packages/scanners/tests/cache-guides.test.ts` | 8 tests for the pure halves: an unverified pin refuses everything, moved bytes refuse as a content review, an undigested guide and an unlisted guide are refused by name, the manifest carries digests and no text, a guide whose text was never supplied is not written empty, the provider arm passes on a verified cache and fails on a mismatched one. |
| `.gitignore` | `.sus-cache/` — upstream text is not copied into the repository (D06 stays open). |
| `docs/RESEARCH_SOURCES.md` §5/§9/§10 + new §11, `evals/research/modern-web-guidance/COMPATIBILITY.md` | Say what is measured, what is refused and what is still `not-run`. |

byte sequence `verify-pin.mjs` measured on 2026-11-16 — not a re-fetch of whatever the host returned

is the cap working, and the record shows the reason instead of hiding it.

## What this does not claim

- **Effectiveness stays `not-run`.** A paired comparison needs a host model to produce output with and
  without the provider over the same tasks. No shipped harness runs a model, so no comparison is
  made. `paired-run.json` writes both extra arms as `not-run` with that reason.
- **Correctness is untouched.** A digest says which bytes exist, nothing about whether the guidance
  is right. No guide text is quoted anywhere in this repository.
- **Unpinned guides stay unreachable.** The pin enumerates four of ~250; the loader can only serve
  those four by construction.
- **Licence is not decided.** The cache is git-ignored and no text is vendored; copying or quoting
  any of it still needs the Apache-2.0 notice, upstream URL, revision and path (D06 open).
- **A cache is operator state, not a build input.** `pnpm verify` and `pnpm regression` never look at
  `.sus-cache/`; with no cache the paired run exits 3 (`not-run`), which is the truthful state of a
  machine that has not opted in.

## Rollback

Delete `research-cache-loader.ts`, both scripts and their tests; revert the docs and the
`.gitignore` line, and remove `.sus-cache/`. The provider falls back to `not-installed`, which is
exactly the state before this task — and the record says so instead of pretending otherwise.
