# T1041 — an HTML file scope attributes by route; a component scope still refuses

**Task:** the descriptor→file map R8 lacked. Rather than invent one, this adds the single attribution that
is true without it: **a static HTML file is the page it serves.**
**Branch / base:** `chore/continuation-reconciliation` after T1040.

## Verdict

**Pass**, with the map itself still absent and now correctly labelled as unnecessary for HTML and
impossible for components.

| Scope | Before | Now |
| --- | --- | --- |
| `component-path checkout.html` | exit 3, "no file can be attributed" | **attributes the `/checkout.html` route**, proposes its findings, exit 0/1 |
| `component-path Card.tsx` | exit 3 | exit 3, unchanged, remedy named |
| HTML file whose route is clean | exit 3 | **exit 0**, "found nothing to change" |
| selector / page | unchanged | unchanged |

## The rule

`htmlScopeRoute(reference, target, targetIsDirectory)` computes the route exactly as the audit does
(`index.html` collapses to its directory), then the selection is restricted to findings on that route.
The basis travels with the proposal:

```
Attribution: this HTML file is the page it serves, so the audit findings measured on the `/checkout.html`
route are findings about this file.
```

Nothing maps `input#email` to a file, because nothing can: the file *is* the unit the audit measured.

## A counting bug this exposed

Findings on **other routes** were counted as `unattributed`, which made a clean HTML file scope exit **3**
("nothing in scope was measured") because a sibling page had findings. They are now counted as out of
scope and named separately — "N finding(s) on other routes (this file serves only `/index.html`)" — so
"could not attribute" and "belongs to another page" are no longer the same number.

## Proof

`packages/eval-core/tests/bestpractice.file-scope.test.ts` — 4 tests, green:

1. an HTML file scope on a page with an `img` missing alt proposes items, prints the attribution line and
   the route, and does not exit 3;
2. a component scope (`Card.tsx`, present on disk) still exits 3 with the remedy;
3. a clean HTML file scope exits **0** with "found nothing to change";
4. `htmlScopeRoute` derives `/` and `/checkout.html` the same way the audit does, returns null for
   `.tsx` and for a selector scope.

## Stated limits

- Only `.html`/`.htm` files. A build output that inlines a component into a page is attributed to the
  *page*, not to the component — that is the honest attribution, and the proposal says which route it used.
- A route the audit did not measure cannot be attributed: a scope on an HTML file outside the target's
  root returns null and falls back to the refusal path.
