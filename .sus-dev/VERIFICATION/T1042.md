# T1042 — a scope path must not depend on how it is spelled

**Found by:** re-running `docs/AUDIT_PACKET.md`'s reproduction commands on a fresh `--depth 1` clone at
`e5b6ad2`, as preparation for the commissioned audit (D35).
**Branch / base:** `chore/continuation-reconciliation` after `e5b6ad2`.

## Verdict

**Pass.** One real defect, found by executing the instructions rather than reading them.

## The defect

`htmlScopeRoute` (T1041) compared a lexical path with a lexical root. macOS `/tmp` is a symlink to
`/private/tmp`, so a scope named `/tmp/site/page.html` against a target resolved as
`/private/tmp/site` produced `../..` and no route — the scope silently fell back to "a file scope cannot
attribute…", exit **3**.

| Invocation | Before | After |
| --- | --- | --- |
| `--scope "$PWD/fixtures/bestpractice/states-flat/index.html"` in a normal tree | 2 items, exit 0 | 2 items, exit 0 |
| the same in `/tmp` (symlinked path) | **exit 3**, "cannot attribute the 80 finding(s)" | 2 items, exit 0 |
| `--scope …/packages/eval-core/src/index.ts` | exit 3 (correct) | exit 3 (correct) |

The failure mode is the one this project treats as worst: an answer that depends on the spelling of an
input, phrased as an honest refusal. It would have looked like a design decision rather than a bug.

## The fix

Both the file and its root are canonicalised (`realpathSync`, guarded by `existsSync`) before the relative
route is computed, and the canonical file is returned. Nothing else changes: the route derivation still
matches the audit's own (`index.html` collapses to its directory).

## Proof

- `packages/eval-core/tests/bestpractice.file-scope.test.ts` — 5 tests, green. The new one builds a symlink
  alias of the site and asserts the alias and the direct path produce the **same** route.
- The audit packet's commands were re-run on a fresh clone: unauthorized host → exit 2 with the reason;
  HTML file scope → 2 items, exit 0; component scope → exit 3 with the remedy.
- `scripts/studio/bridge.mjs --json` on the fresh clone prints `{"event":"ready", …, "readOnly":true}` with a
  session id and token, and nothing else.

## Stated limits

- Only the two occurrences of this path comparison are canonicalised; other places that compare paths were
  not swept, and this receipt does not claim a repository-wide audit of path handling.
- `realpathSync` on a path that disappears between `existsSync` and the call would throw; the scope is a
  user-supplied file, so the failure is a refusal rather than a wrong answer.
