# T1050 — apply path containment at the audited revision (audit finding T1003-5; fixed by T1044)

Date: 2026-11-18 · Agent: zcode-audit · Branch chore/continuation-reconciliation

## Disposition

The audit found the `ApplyEngine` joined proposal paths onto the root with no containment of its
own at revision `69c8a45` (containment existed only in `PreviewSession.refusePath`, while
`ApplyRequest.session` is an interface any object satisfies). Before the audit closed, the
builder's commit **`cfd3049`** (task **T1044**) landed exactly the demanded guard: `insideRoot`
(realpath the parent, leave the leaf unresolved, so a leaf symlink is replaced rather than written
through) plus the `path-outside-root` refusal in the apply flow. This task record closes the
finding; the fix's full evidence lives in `.sus-dev/VERIFICATION/T1044.md`.
