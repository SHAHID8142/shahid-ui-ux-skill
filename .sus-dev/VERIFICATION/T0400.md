## Why a schema and not a paragraph of advice

"Derive a direction from the brief" is unenforceable advice. The failure mode is
specific: three candidates that are one idea restated, described in adjectives,
chosen because one sounded better, with no record of anything being *refused*.
That failure is checkable, so it is checked:

| Code | What it catches |
| --- | --- |
| `unknown-default` | a refusal naming a taxonomy id that does not exist — "we avoided slop" nobody can verify |
| `chosen-refuses-nothing-blocking` | the chosen direction refuses only advisory defaults, so the choice is undefended |
| `duplicate-thesis` | three restatements of one idea |
| `unexplained-rejection` | a candidate that lost with no recorded reason |
| `anti-references-borrowed` | project-level anti-references that are copies of a candidate's list |

The schema itself enforces exactly three candidates, no unknown fields, a reason
for *each* loser, and the chosen one refusing ≥1 default; severities come from
the existing anti-slop taxonomy, so this task adds no second source of truth
about what "slop" is.

## The knowledge file

`skill/references/direction.md` describes the six-step sequence (job before
adjectives, differentiation on the brief's axis, mechanism per candidate, named
refusals, defended choice, project-level anti-references) and points at the
worked example as the specification. It states its limits: the record proves the
alternatives were argued, not that the winner is best; refusals are taxonomy ids
today; no numeric baseline lives here.

## Honest limitations

- Two of my own tests were wrong before the code was: I asserted the schema would
  reject a one-entry `rejected` list *and* that semantics would then explain it —
  the semantic case needed two entries with the wrong one explained. The test now
  separates schema failure from semantic failure explicitly.
- `rejected` is an array rather than a keyed record because zod v4 requires
  exhaustive keys for enum records; the array states the same obligation without
  a fake fourth option.
- Direction quality (is c2 actually better than c1?) remains a judgement; only
  the *argument* is machine-checked.
