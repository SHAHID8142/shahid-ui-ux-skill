## The two invariants the schema enforces

1. **A `fact` must carry `observed` and `evidence`.** `composeProposal` refuses with
   `fact-without-observation` otherwise. This is the schema-level answer to "no manufactured metrics":
   a measured claim with nothing behind it cannot be constructed, so it cannot be rendered.
2. **A `heuristic` may not be ranked P0 or P1.** Refused with `heuristic-ranked-blocking`. Judgment
   may be valuable and still not blocking; the severity ladder is reserved for measured harm.

Refused scopes: `ambiguous`, `not-found`, `advisory` (a screenshot rectangle is not source) and
`rejected` all yield `scope-not-resolved` — with the clarifier quoted in the refusal detail — and an
empty item list yields `no-items` instead of an empty promise.

## Approval cannot drift off its content

The record carries `digest` = SHA-256 over canonically serialised `{scope, focus, items, untested}`.
`authoriseApply` refuses in four named cases and allows only the fifth:

| Case | Result |
| --- | --- |
| `hunkIds: []` | `empty-approval` |
| digest ≠ proposal digest (content edited after approval) | `stale-digest` |
| approved id not in the proposal | `unknown-hunk` |
| hunk in a dimension listed as untested | `untested-dimension` |
| matching digest + known hunks + measured dimensions | allowed |

The last refusal is the interesting one: an approval for a change in a dimension nothing measured
would produce an "improvement" nobody could verify, so it is refused rather than warned about.

## Applying stays in Studio

`packages/studio-bridge/src/apply.ts` (T0707) is the only writer: it refuses without a live,
content-bound grant, rechecks the file hash so the user's uncommitted edits are never overwritten, and
restores preimages byte for byte on rollback. This module hands it a proposal and a digest; it does
not add a second writer — issue #15's explicit instruction.

## What this does not claim

- **No diff, no patch, no plan file.** Remedy + test plan are text; patch generation belongs to
  Studio's preview path.
- **No command.** Nothing routes `sus.bestpractice` yet (T1023), so nothing here is reachable from a
  host.
- **No dimension is measured by this module.** It records what the audit measured; a proposal whose
  `untested` list is long is honest, not complete.
- **Rollback semantics are T0707's**, cited not re-tested here.

## Rollback

Delete `bestpractice/proposal.ts`, its exports, its test file and the two doc sections. Nothing imports
the module, so the audit pipeline and Studio are untouched.
