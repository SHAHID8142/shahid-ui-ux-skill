## Design decisions

**Provenance is a precondition, not a label.** `VariantSession.open` refuses the
whole comparison when any variant cannot be attributed — no intent id, no
generator model, a `promptSha256` that is not a digest, no run id, or a
timestamp that is not one. It also refuses a set whose provenance answers a
*different* intent. A proposal a user cannot trace is an anonymous edit to their
product, so it never reaches the comparison UI.

**Three viewports, one document.** Each variant is wrapped once and the same
`srcdoc` is reused for mobile/tablet/desktop frames (390/768/1280), so the
studio scales one render per variant instead of three. A test asserts the
documents are literally identical across viewports — the "simultaneous" promise
is structural, not a hope.

**Discard is cheap by construction.** `discard()` releases the markup reference
and reports the bytes released; it does not re-render, re-serialize or recompute.
Provenance survives for the audit trail. `heldBytes()` makes cheapness
measurable, and the accept test asserts only the accepted payload is still held
afterwards. Mutation-checked: commenting out the release breaks 4 tests.

**Variant markup is data, never code.** Two independent controls:
1. markup containing `<script>`, `<iframe>`, `<object>/<embed>`, `<base>`, an
   inline `on*=` handler or a `javascript:` URL is refused at open;
2. every frame is **fully sandboxed** — `sandbox: []` means scripts, forms,
   same-origin and popups are all denied, so even a mistake in control 1 cannot
   reach the host or the page under test.

**Accepting is a trusted-host action.** The model exposes no event hook; a test
asserts the surface has nothing matching an event/listener/subscribe/handler
name and that no DOM API appears in the snapshot. This honours the peer finding
that isolated worlds isolate JS state but *not* DOM events.

**Rollback matches the recorded risk.** HMR state loss is not recoverable in
place, so `accept()` returns `applyStrategy: 'full-page-reload'` — the recorded
rollback — rather than pretending a hot swap is safe.

## Refusals covered

`untrusted-markup` (6 payload classes), `unknown-variant`, `already-decided`,
`already-discarded`.

## Honest limitations

- Variants are rendered as static markup in an inert frame. A hydrated variant
  (framework islands) is not executed, so a variant whose appearance depends on
  its own JS is shown in its unhydrated form. That is deliberate — running a
  candidate edit's scripts before approval is the exact capability the safety
  contract withholds — but it limits how faithful the preview is for such
  proposals, and the receipt says so rather than hiding it.
- The visual diff is side-by-side comparison plus the comparison digest, not a
  pixel diff; pixel regression is T0905's harness.
- `sandbox: []` also blocks images and CSS loaded over the network in some
  browsers' sandbox rules; variant markup should be self-contained. Not
  enforced here.
