## Guard rails (tested)

- A host cannot be both a compatibility row and untested: `buildCompatibility` throws
  `host "…" is listed as untested and has a compatibility row`. A matrix that says both would be the
  exact false claim issue #16 is about.
- The untested section never renders a tier column: it lists id, product, why untested, and what
  would make it a row (`smoke-host.mjs` run on that host against this artifact).
- `statusText` prints untested hosts as `tier=untested evidence=missing`, so `sus status` cannot
  imply coverage either.

Tests: `packages/adapters/tests/compatibility.test.ts` — 19 pass, including the contradiction refusal,
the status rendering, and a check that the tiered table contains exactly the measured rows.
