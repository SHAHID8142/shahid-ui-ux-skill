# T1035 — a performance number says what kind of number it is (issue #21 R11)

**Task:** issue #21 R11: SUS has lab measurements only, and no human benchmark or field data exists, so
no comparative claim is permitted. A reader who saw a duration could not tell that from the number.
**Approval:** D32 issue triage inside D28; the owner's `go ahead` on the R-series.
**Branch / base:** `chore/continuation-reconciliation` at `956b50f`.

## Verdict

**Pass.** The notice travels with every performance number instead of waiting on
`docs/LIMITATIONS.md`; the claim gate is unchanged and still forbids a comparative claim.

## The text, and why it names all three things

```
lab measurement: Lighthouse in this browser, no field data, no comparative claim
```

- **lab measurement** — where the number came from (this browser, this machine);
- **no field data** — what it is not (real users);
- **no comparative claim** — what may not be inferred from it (a ranking against another site).

## Where it now appears

| Surface | Placement |
| --- | --- |
| `audit.md` | a blockquote under Summary, whenever the report contains a Lighthouse check |
| `audit.json` | last line of the `lighthouse-budgets` check detail — **including when the check passes**, because a lab pass is still a lab pass |
| budget findings | appended to each `Budget miss: …` detail, so it travels with the remediation |
| proposal markdown | `- Measurement basis: …` beside each `performance` item, once per item |
| `docs/LIMITATIONS.md` | stated in the list readers are told to read first |

## Proof

`packages/eval-core/tests/lab-notice.test.ts` — 3 tests, green:

1. the constant says all three things;
2. a real deep audit: `audit.md` contains it, the G5 check detail ends with it (asserted on a **passing**
   run, which is the harder case), and every budget finding's detail contains it;
3. a performance item's proposal renders it exactly once, and a page-scope selection still yields what
   it yielded before.

## Stated limits

- This is labelling, not new measurement: no field data was collected, and the claim gate still refuses
  comparative language.
- Non-performance dimensions are untouched — a tap-target measurement is not a lab-vs-field number.
