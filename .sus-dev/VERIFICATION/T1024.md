Every fix is a real edit applied to a temporary copy: pad to 44×44, wrap the nav, label and enlarge

## Four defects found while measuring (fixed here)

1. **`capture-matrix` findings were filed by check, not by meaning.** Tap-target defects are a11y
   (WCAG 2.5.8) but mapped to `responsive`, so an a11y scope on a CTA proposed nothing — the first
   example run failed for exactly that reason. `dimensionForFinding` now splits the check by finding.
2. **A parent scope did not own its children.** `#signup`'s undersized input is a defect *of the
   form*, but attribution was an exact descriptor match. `ScopeTarget.descendants` now carries bounded
   descendant descriptors (≤120, no text), so a form or table scope owns what is inside it.
3. **One defect produced nine items.** Overflow was listed once per viewport/theme/reduced-motion
   combination. Items are now grouped by element plus topic, keeping the worst severity, the widest
   measurement and the tightest expectation, with the combinations listed once.
4. **Leaf-only overflow probing named the wrong element.** A 720 px nav overflows the viewport even
   though none of its links do; the probe only recorded childless elements and reported the table
   `caption` instead. It now records the outermost overflowing element in each branch, which is also
   what a scoped proposal can attribute.

## What this does not claim

- **Motion stays `not-run`.** `transition-oracle` needs a scripted interaction; no example drives one.
  The reduced-motion guard ships in the fix, and nothing here measures it.
- **No guideline text** was read or copied; the proposals are the audit's findings. D06 remains open.
- **No axe attribution.** axe findings are located by rule id and are counted as attributed elsewhere.
- **Nothing was applied** to a repository fixture; the fixed stage lives in a temp directory.
