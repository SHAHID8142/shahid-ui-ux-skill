## The gate

`scripts/lib/doc-drift.mjs` (pure, no I/O) + `scripts/lib/doc-drift.d.mts`, called from
`scripts/check-continuation.mjs` §5b with `TASKS.json`, `docs/compatibility.json` and the
`BUILD_COMPLETE_PUSHED` line from `.sus-dev/STATE.md`.

| Rule | Fails when |
| --- | --- |
| `stale-task-claim` | a live doc calls a done task `pending` |
| `premature-task-claim` | a live doc calls a pending task done |
| `build-flag-contradiction` | `EFFECTIVE_REQUIREMENTS.build_complete_pushed` ≠ `STATE.md` |
| `stale-host-evidence` | a live doc cites smoke evidence other than `compatibility.json`'s, or does not name the recorded state |
| `historical-document-unmarked` | a document is listed historical but carries no banner near the top |
| `stale-count-claim` | a hand-maintained "N of M done" differs from `TASKS.json` |
| `effective-requirements-unparseable` | the manifest is not valid JSON |

Historical documents are exempt only when they say they are historical: an exemption without a
banner would launder the drift the rules exist to catch.

`[FAIL] live documents do not drift …`; with the fixed text it reports `[PASS]`.
