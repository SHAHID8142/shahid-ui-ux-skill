## Failures encountered and resolved (recorded honestly)

1. AxeBuilder requires pages from explicit `browser.newContext()` — fixed.
2. Chrome 136+ refuses remote debugging on a default profile (the exact
   constraint ADR-003 records): lighthouse's default launcher failed with
   ECONNREFUSED on 9222. Fixed by launching Chrome-for-Testing via
   chrome-launcher with an implicit fresh profile and passing the port to the
   programmatic lighthouse API.
3. First violation injection used a zero-width space — axe computed an
   accessible name from it, so G4 passed (test bug). Replaced with a truly
   empty button; the end-to-end negative then worked.
4. LCP can read 0 when a trace misses the entry on a fast cold load
   (lighthouse flake, matches the T0152 rollback note "masking + retry"):
   documented retry-once-on-zero policy in the test; standalone probe
   (LCP 772 ms) confirmed real values.
5. chrome-launcher kill() is not a promise — wrapped; `killAll()` removed
   (heavy-handed: could kill other processes' Chrome instances).
