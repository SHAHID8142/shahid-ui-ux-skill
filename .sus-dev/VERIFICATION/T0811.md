## The contract each primitive encodes

| Primitive | The thing that actually breaks in production |
| --- | --- |
| `pagination` | Total and range in text; page in the URL; focus to the results heading; a page past the end lands on the last page, not an empty table implying no data |
| `tabs` | One tab stop with roving focus; panel associated via `aria-controls`; per-panel loading/empty/error so one failing panel cannot blank the strip |
| `accordion` | Heading containing a button with `aria-expanded`; measured height inside the motion band; required/legal content never collapsed |
| `drawer` | Modal or not decided explicitly; focus enters and returns to the opener; unsaved edits guard dismissal; fits the visual viewport with a keyboard open |
| `dropdown` | Menu (actions, closes on activation) vs select (values, keeps its value); full keyboard contract; flips at viewport edges; destructive items separated and confirmed |
| `breadcrumb` | Hierarchy, never click history; current page is text with `aria-current`; middle collapses into a real expansion; two levels render nothing |
| `avatar` | Always resolves to a name; deterministic initials rather than a broken image; presence described in text; `+N` names the rest |
| `badge` | Three jobs, three shapes; status never colour-only; counts cap at 99+ with the exact number in the accessible name; `unknown` is a state |
