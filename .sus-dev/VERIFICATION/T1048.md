# T1048 — the CI host-smoke step can actually fail the build (audit finding T1003-3) + T1075 trigger/comment symmetry (T1003-31)

Date: 2026-11-18 · Agent: zcode-audit · Branch chore/continuation-reconciliation

## What changed

- `.github/workflows/ci.yml` (host-smoke job): `node scripts/coord/smoke-host.mjs > "$RUNNER_TEMP/smoke.json"`
  replaces `… | tee "$RUNNER_TEMP/smoke.json"`, with a comment explaining why (GitHub's default run
  shell is `bash -e` **without pipefail**, so a pipe reported `tee`'s status and the smoke's exit 1
  was discarded — the only CI surface exercising the audit CLI end to end could never turn red).
- `.github/workflows/ci.yml` (header): "main is never built here" reworded to scope the claim to the
  push trigger (push ignores main; an unfiltered `pull_request` builds PR merge commits) — T1075,
  audit finding T1003-31.
- `packages/schemas/tests/ci-actions-pinning.test.ts`: two new describe blocks — the smoke step must
  run by redirection with no pipe in the line and must still write `$RUNNER_TEMP/smoke.json`; the
  header must contain "push trigger ignores main" and not the old unqualified claim.

## Evidence

- `pnpm -w exec vitest run packages/schemas/tests/ci-actions-pinning.test.ts` → **8/8 pass**
  (5 pinning tests + 3 new). The redirection test fails if the pipe returns: it asserts
  `/smoke-host\.mjs\s*>\s*\S+/` **and** `not.toContain('|')` on the exact run line.
- Shell-semantics negative control (executed):
  `bash -e -c 'node -e "process.exitCode=1" > /tmp/smoke-sim.json; echo redirect_exit=$?'` →
  shell exits 1, the echo never runs (a red step, as intended);
  `bash -e -c 'node -e "process.exitCode=1" | tee /tmp/smoke-sim2.json; echo pipe_exit=$?'` →
  `pipe_exit=0` (the defect this fix removes).
- The smoke script's exit contract is unchanged (`scripts/coord/smoke-host.mjs:157`
  `process.exitCode = failed ? 1 : 0`); redirection preserves it.

## Not verified here

  the shell-semantics control demonstrates the mechanism GitHub uses; the next CI run on this commit
  will show the step green with the receipt on disk exactly as before.
