# UX-laws catalog — sources and licence position

- Sources are cited **by URL only** in `catalog.json`: `https://lawsofux.com/` (curated reference,
  not primary science) and `https://www.nngroup.com/articles/ten-usability-heuristics/` (Nielsen's
  heuristics, which the catalog deliberately distinguishes from named UX laws), plus per-law
  encyclopedia links for the underlying science.
- **Nothing was copied verbatim from any source.** Every description, coverage statement and
  decision reason in `catalog.json` and `docs/UX_LAWS_COVERAGE.md` is original writing by the
  build agent. The licence decision for third-party text is still open (D06); this catalog is
  written so that it stays valid whatever the owner decides.
- Evidence tiers are the build agent's classification, not the sources': `strong-empirical`
  (established perceptual/psychophysical science), `replicated-with-boundaries` (real effect,
  context-dependent), `popular-heuristic` (design vocabulary without decisive evidence),
  `contested` (mixed or criticized record — flagged, with the criticism stated).
- Access date for all URLs: 2026-11-19.
